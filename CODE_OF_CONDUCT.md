# Código de conduta

Queremos uma comunidade acolhedora para pessoas de diferentes experiências, origens e níveis de conhecimento.

- Trate as pessoas com respeito e critique ideias e código de forma objetiva.
- Aceite feedback e ajude quem está começando.
- Não pratique assédio, discriminação, ameaças ou exposição de dados pessoais.
- Não publique fotografias, nomes completos, gravações ou informações identificáveis de crianças nos espaços do projeto.

Estas regras valem para issues, pull requests e discussões. Para relatar uma violação, procure os mantenedores por um canal privado disponibilizado no perfil GitHub da organização. Se não houver canal privado disponível, solicite um contato sem publicar os detalhes do incidente. Os mantenedores podem remover conteúdo, advertir ou restringir a participação, conforme a gravidade e reincidência.
